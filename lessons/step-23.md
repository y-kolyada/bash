## Задание 23

**Хочу:** на телефоне страница открывается на своём тексте, а меню разделов остаётся в одном
касании сверху - свёрнутым в строку.

**Измерено до работы** (экран 390×844, любая страница уровня):

| Что | Значение |
| :-- | --: |
| меню начинается на | 149px |
| высота меню | 724px |
| заголовок страницы начинается на | 901px |
| это в экранах | **1.07** |

Читатель на телефоне пролистывает целый экран меню, прежде чем увидит, на что он нажал. И
так на каждой странице - не только после клика по меню, но и при переходе из поиска или по
чужой ссылке. **Разделы текущей страницы на телефоне не показываются вовсе**
(`display: none`), то есть навигации по странице у телефонного читателя нет никакой.

**Решение Архитектора: вариант Б - меню сворачивается.** Вариант «текст первым, меню под ним»
отклонён: «зачем мне бегать вниз, чтобы быстро что-то выбрать».

**Как это выглядит:**

```
┌──────────────────────────────┐
│ Разделы сайта · 1 · Ключевые компоненты   ▾ │   ← одна строка, касание разворачивает
├──────────────────────────────┤
│ Заголовок страницы            │   ← текст начинается здесь
│ Главная мысль страницы...     │
```

Развёрнутое меню показывает те же пятнадцать пунктов и разделы текущей страницы, вложенные в
её пункт - ровно как на рабочем столе после занятия 22. Отдельного блока «на этой странице»
на телефоне не появляется: он внутри меню, и это одно и то же место.

**Предикаты:**

1. **Заголовок страницы виден без прокрутки.** На экране 390×844 верх `main` меньше высоты
   экрана - на всех страницах всех четырёх языков. Сейчас 901px при экране 844px.
   **Чем проверяется:** машиной - браузерная проверка телефоном, положение `main` против
   высоты окна; краснеет на нынешней раскладке.

2. **Меню в одном касании, и видно, где ты.** В свёрнутом виде строка содержит название
   текущей страницы. После касания видны все пятнадцать пунктов, словарь и разделы текущей
   страницы внутри её пункта. Касание любой ссылки - по странице или по разделу - сворачивает
   меню обратно: читатель остаётся с текстом, а не с меню.
   **Чем проверяется:** машиной - браузерная проба на телефоне: развернуть, сосчитать пункты,
   нажать на раздел, проверить, что меню свёрнуто и экран стоит на этом разделе.

3. **Рабочий стол не изменился.** На ширине от 56rem свёрнутой строки нет вовсе, панель
   липкая, разделы вложены в пункт своей страницы, подсветка последнего раздела на дне
   работает. Все шесть проверок зелёные.
   **Чем проверяется:** машиной - `./check.sh` целиком, две высоты окна.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Вариант раскладки | **Б:** меню сворачивается в строку. Вариант А (текст первым, меню внизу) отклонён. |
| Память состояния | **Не запоминаем.** При открытии любой страницы меню свёрнуто: читатель пришёл читать. Нового ключа хранилища не заводим. |
| Разделы страницы на телефоне | Показываются **внутри развёрнутого меню**, вложенными в пункт своей страницы. Отдельного блока и заголовка нет. |
| Без JavaScript | Меню остаётся развёрнутым, как сегодня. Это осознанная деградация: читатель теряет удобство, но не содержание. |

3. **Запоминание состояния между страницами.** Решение Архитектора - не делаем.
4. **Перенос в детский сайт.** Не сейчас: сначала приёмка здесь, перенос отдельным заданием.
5. **Шапка и её закрепление на телефоне.** Не сейчас: отдельный вопрос, и его стоит смотреть
   после того, как меню перестанет занимать первый экран.
