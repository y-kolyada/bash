## Задание 26

**Хочу:** сайт объясняет поисковику и мессенджеру, что он такое, а читателю с клавиатурой и
с читалкой - не мешает.

**Измерено разведкой 2026-10-19** (пять страниц: посадочная, разбор, примеры, вопросы,
словарь):

| Что | Состояние |
| :-- | :-- |
| `<title>` | есть, уникальные, 28-54 знака, одна схема |
| `description` | **нет ни на одной из 68 страниц** |
| `canonical`, `hreflang` | **нет нигде** - четыре перевода конкурируют как разные документы |
| JSON-LD | **нет**; самое выгодное место - банк вопросов, 50 пар «вопрос-ответ» на странице |
| Open Graph | **нет** - ссылка в мессенджере разворачивается пустой |
| `sitemap.xml`, значок сайта | **нет** |
| ссылка «к содержанию» | **нет** |
| переключатель языков | `div` с подписью, которую читалка игнорирует; у ссылок нет `lang` и `hreflang` |
| `prefers-reduced-motion` | **не уважается**: прокрутка всегда плавная |

**Предикаты:**

1. **Каждая страница объявляет себя поисковику и мессенджеру.** На всех 68 страницах есть:
   `description` (первое предложение лида, обрезанное по границе до 160 знаков), `canonical`
   на живой адрес, `hreflang` на три языка-брата и `x-default` на корневую дверь, пара
   `og:title`/`og:description`/`og:url`/`og:type` и `twitter:card`, ссылка на значок сайта.
   Адрес хранится **одной константой** в генераторе - сегодня `y-kolyada.github.io/bash/`.
   **Чем проверяется:** машиной - проверка полей на каждой странице; `check-links.py` -
   «битых: 0»; `build-meta.py --check` краснеет, если текст изменили, а описание не пересобрали.

2. **Смысл размечен там, где это даёт больше всего.** JSON-LD: `FAQPage` на `13`-`15`,
   `DefinedTermSet` на словаре, `TechArticle` на разборах и примерах, `WebSite` на
   посадочной. В корне - `sitemap.xml` со всеми страницами четырёх языков и ни одной лишней.
   **Чем проверяется:** машиной - JSON-LD на каждой странице разбирается как валидный JSON;
   число вопросов в разметке равно числу вопросов на странице (50 на каждой из трёх);
   `sitemap.xml` содержит ровно 68 адресов, и каждый открывается.

3. **Три пробела доступности закрыты.** Ссылка «к содержанию» - первая в порядке обхода
   клавиатурой, видна при получении фокуса и спрятана иначе. Переключатель языков - область
   с подписью, у каждой ссылки `lang`, `hreflang` и полное имя языка для читалки. При
   системной настройке «меньше движения» прокрутка кнопками мгновенная, а не плавная.
   **Чем проверяется:** машиной - браузерная проверка: первый `Tab` попадает на ссылку
   «к содержанию»; у четырёх ссылок языков есть `lang` и `hreflang`; при
   `prefers-reduced-motion: reduce` прокрутка завершается в пределах кадра.

**Дата:** 2026-10-19

**Кто написал:** черновик набрал ИИ (Claude Code, Opus 5) по решению Архитектора.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Откуда брать описания | **Из лида страницы.** Он написан именно для этого; 68 описаний руками не пишем. |
| Какой адрес писать | **Живой:** `y-kolyada.github.io/bash/`. Канонический адрес, который не отвечает, выбрасывает страницу из индекса. Домен - одной константой в генераторе; переезд на `bash.ai.b1space.com` будет одной строкой. |
| `robots.txt` | **Не сейчас:** на GitHub Pages он действует только из корня домена, а корень чужой. Станет нашим после переезда. |
| Картинка для карточки | **Не сейчас:** её нет. Значок сайта берём простой, концепцию значков для серии продумываем отдельно. |
| Вычитка описаний | Отдельное задание Жемини после того, как генератор их напечатает. |

## Границы: что в задание 26 не входит

1. **Тексты страниц.** Не сейчас: генератор берёт описание из того, что уже написано; если
   лид плох как описание - это правка текста, и её делает вычитка отдельным заданием.
2. **Картинка для карточки пересылки и концепция значков серии.** Не сейчас: это работа
   дизайна, а не разметки, и она касается всех одиннадцати сайтов сразу.
3. **`robots.txt` и перенос на свой домен.** Не сейчас: решение Архитектора.
4. **Разметка `HowTo`, `Course`, `BreadcrumbList`.** Не сейчас: сначала то, что даёт
   расширенную карточку, - вопросы и словарь.
5. **Перенос в детский сайт.** Не сейчас: отдельным заданием после приёмки.
