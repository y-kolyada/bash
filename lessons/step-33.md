## Задание 33

**Исполнитель:** Claude Code (Opus 5). **Репозиторий:** `courses/b1bootcamp26-site`, ветка
`main`. **Основание:** решение Архитектора - перенести на детский сайт то, что уже проверено
на `devops-bash`. Задание **написано, но в работу не взято**: начинается по слову «делаем».

**Хочу:** ребёнок, открывший занятие на телефоне, видит текст занятия, а не меню; а блок
«На этой странице» стоит там, где его ищут - внутри того пункта меню, на котором читатель
сейчас стоит.

**Откуда это.** Измерено в браузере на 390x844, страница `01.html`:

```
                                     детский сайт   devops-bash после переноса
высота меню                              448px               -
до заголовка занятия                     635px               -
до первой фразы текста                   707px             242px
блок «На этой странице»          после всех восьми пунктов   внутри текущего пункта (69px)
кнопка свёртки меню                      нет                 есть
```

Движки общего корня: код, который наполняет `#tocList`, в двух файлах совпадает дословно. На
`devops-bash` к нему добавлены пять строк, которые кладут контейнер внутрь пункта с
`aria-current="page"`, кнопка свёртки меню и уважение к системной настройке «меньше движения».
Блок «На этой странице» на детском сайте уже есть в разметке (`#pageToc`, `hidden`, в конце
`nav.contents`) - **переставить его движком дешевле, чем перебирать разметку сорока страниц.**

**Поставка первая - только движок.** Три вещи, все в `swa.js` и `style.css`:

1. **Свёрнутое меню на телефоне.** Кнопка `.nav-fold` складывает список занятий в одну строку;
   состояние помнится в хранилище по схеме `swa-<сайт>-<ключ>`.
2. **Вложенный навигатор.** `#pageToc` переезжает внутрь `<li>` с текущим пунктом; на страницах
   без текущего пункта (переводы посадочной) остаётся там, где стоит.
3. **Меньше движения.** При `prefers-reduced-motion: reduce` прокрутка кнопками мгновенная.

Разметка сорока страниц при этом меняется **одной правкой на страницу**: номер версии в ссылках
`style.css?v=8` → `?v=9` и `swa.js?v=2` → `?v=3`, иначе вернувшийся читатель получит старый
движок.

**Предикаты:**

1. **На телефоне страница открывается на тексте.** На 390x844 расстояние от верха документа до
   первой фразы занятия меньше **300px** на всех пяти темах (сегодня 707px), кнопка свёртки
   есть, и развёрнутое меню возвращается в прежний вид.
   **Чем проверяется:** машиной - `node tests/test-nav.mjs` печатает измеренное расстояние и
   краснеет, если оно больше 300px.

2. **Блок «На этой странице» стоит внутри текущего пункта меню.** На всех страницах занятий
   контейнер `#pageToc` - потомок того `<li>`, в котором лежит `aria-current="page"`; до него от
   верха документа на телефоне меньше **200px**.
   **Чем проверяется:** машиной - тем же тестом.

3. **В разметке не изменилось ничего, кроме номера версии, и проверка зелёная.**
   **Чем проверяется:** машиной - `git diff --stat` в детском репозитории показывает правки
   только в `swa.js`, `style.css`, `tests/test-nav.mjs`, а в сорока страницах только строки со

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Объём поставки | Только движок плюс номер версии. Генератор и разметка головы - отдельными заданиями. |
| Номер версии | Руками, по схеме детского сайта (`?v=9`, `?v=3`). Одна константа появится в поставке Б вместе с генератором. |
| Восемь языков | Перенос движковый, текста не касается: переводить нечего. |
| Артефакты занятия | Задание и запись живут в `courses/bash/lessons/`, как при переносе занятия 20. |
| Коммиты | Ветка `main` детского репозитория; коммитит ИИ локально, пушит Архитектор. |
