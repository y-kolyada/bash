## Задание 4

**Хочу:** содержание всего сайта на русском языке - тринадцать оставшихся страниц, `02.html` … `14.html`. Каркас стоит с занятия 2, `01.html` задала образец вёрстки; дальше нужен смысл, а не оснастка.

**Предикаты:**

1. **Тринадцать страниц существуют и встроены в сайт.** `02.html` … `14.html` на русском открываются, у каждой свой `<title>`, шапка с `ai|`, `devops-bash` и янтарной плашкой `Bash`. Каждая открывается блоком «Главная мысль» из 3–7 фраз и заканчивается секцией «Артефакты». В левой навигации **всех** страниц сайта все четырнадцать пунктов стали ссылками и потеряли метку «· будет»; на лендинге список разделов - тоже ссылки. Ни один пункт переключателя языков не ведёт в 404: для каждой новой страницы есть честные заглушки `-en`, `-uk`, `-de` со ссылкой на русскую версию.

2. **Содержание соответствует уровню и типу страницы.** Страницы `02`–`08` (написание скриптов, сила, слабости, взаимосвязи, три территории практик) - не меньше шести разделов каждая, в каждом разделе пример кода и строка «**Что спрашивают:**». Страницы `09`–`11` (примеры Noob / Pro / IGL) - не меньше пяти разборов на уровень, каждый с кодом и объяснением, почему именно так. Страницы `12`–`14` (вопросы Noob / Pro / IGL) - по пятьдесят вопросов, ответ в одну-две фразы и строка, зачем этот вопрос задают.

3. **Машина подтверждает.** `./check.sh` печатает ЗЕЛЁНОЕ. `node glaza.mjs` на **каждой** странице сайта печатает «за край ничего не вылезло» и возвращает 0 - ни один блок кода не уезжает за правый край на 390px.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Язык | **Только русский.** Перевод - отдельной работой позже, когда текст перестанет меняться. |
| Заглушки | Для каждой новой страницы создаются `-en`, `-uk`, `-de` по уже принятому паттерну: иначе переключатель языков начнёт вести в 404, а это запрещено предикатом 4 задания 2. |
| Приёмка | Выполняется Архитектором после возвращения. Машинная часть закрывается сразу, содержательная - глазами. |
| Коммиты | ИИ не коммитит. Сообщения коммитов готовятся отдельно, по страницам. |

## Границы: что в задание 4 не входит

1. Перевод содержания на `EN`, `UK`, `DE`.
2. Правка `check.sh` под новые предикаты - это занятие 4 курса.
3. Автоматический запуск проверки на коммит - занятие 5.
4. Подсветка синтаксиса, нумерация строк, поиск по сайту.
