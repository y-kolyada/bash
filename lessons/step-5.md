# Задание

**Это пишет или утверждает Архитектор, до того как ИИ тронет файлы продукта.**

> **Предикат** - утверждение, которое можно проверить и ответить «да» или «нет».
> **Хотя бы один предикат должен проверяться машиной.**

---

## Задание 5

**Хочу:** словарь, который соответствует всему сайту, а не только первой странице. Сейчас в нём шесть терминов, написанных, когда существовал один раздел из четырнадцати.

**Предикаты:**

1. **Терминов двадцать два, и каждый оформлен одинаково.** Шесть прежних остаются; добавляются шестнадцать: поток и дескриптор, перенаправление, переменная окружения, `PATH`, `IFS`, шаблон имён, сигнал, ловушка, режимы оболочки, POSIX и bashism, режим проверки, идемпотентность, атомарность, блокировка, контракт инструмента, радиус поражения. У каждого термина есть название, одна фраза для узнавания, абзац механики и строка «Где встретилось впервые» со ссылкой на конкретный раздел страницы сайта.

2. **Порядок следует уровням сайта, а не месту первого появления.** Термины разделены на три блока с заголовками - механика, практика, решения, - и боковой навигатор показывает и блоки, и термины. Словарь по-прежнему открывается блоком «Главная мысль» и заканчивается секцией «Артефакты».

3. **Машина подтверждает.** Каждая ссылка «Где встретилось впервые» ведёт на якорь, который существует на целевой странице, - это проверяет скрипт, а не глаз. `./check.sh` печатает ЗЕЛЁНОЕ, `node glaza.mjs glossary.html` возвращает 0, длинных тире в файле ноль.

**Дата:** 2026-10-17

**Кто написал:** черновик набрал ИИ по скилу `zadanie`; список терминов выведен из подсчёта, на скольких страницах каждый встречается.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Критерий включения | Термин встречается на трёх страницах и больше - или это понятие, которое мы ввели сами и которого нет в `man bash` (контракт инструмента, радиус поражения). |
| Что не включаем | Имена инструментов: `shellcheck`, `cron`, `jq`, `awk`, CI. Это не понятия, они объяснены там, где встречаются. |
| Язык | Только русский. |
