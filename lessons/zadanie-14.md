## Задание 14

**Хочу:** поиск по сайту в панели инструментов. Пятнадцать разделов и 150 вопросов нельзя
обойти глазами, а перед собеседованием читатель ищет не раздел, а вопрос.

**Предикаты:**

1. **Поиск находит то, что на сайте есть, и показывает, где это.** Панель открывается из
   шапки, ищет по языку открытой страницы и показывает для каждого попадания заголовок
   раздела или текст вопроса, страницу, на которой он лежит, и **пометку языка**. Переход
   ведёт прямо в раздел - по якорю, а не на начало страницы. Единица поиска - раздел с якорем,
   карточка словаря и каждый из 150 вопросов отдельно.
   **Чем проверяется:** машиной - запрос `pipefail` находит раздел и вопросы, переход
   открывает страницу с нужным якорем; запрос из трёх букв даёт результат.

2. **Скорость первой загрузки не ухудшилась.** Индекс - отдельный файл, который грузится
   только при первом открытии панели, и в разметке страниц на диске не изменилось ни строки.
   **Чем проверяется:** машиной - замер времени загрузки страницы до и после, разница в
   пределах погрешности; `git diff` по `*.html` пуст.

3. **Индекс не врёт.** Проверка пересобирает индекс и сравнивает с лежащим в репозитории:
   разошлись - КРАСНОЕ. Устаревший индекс опаснее отсутствующего: он находит то, чего уже нет.
   **Чем проверяется:** `./check.sh` → ЗЕЛЁНОЕ, и проверка краснеет на нарочно устаревшем
   индексе.

4. **Найденное видно в тексте, а поиск помнит контекст.** При переходе в раздел найденные
   слова подсвечиваются (`<mark class="search-mark">`), а в шапке левее поиска появляется
   кнопка снятия подсветки. Повторное открытие поиска сохраняет запрос и подсветку выбранного
   пункта в списке. В строке поиска есть кнопка быстрой очистки поля в едином стиле с кнопкой
   шапки.
   **Чем проверяется:** машиной в `tools/check-pages.mjs` - переход подсвечивает слова и
   показывает кнопку снятия, повторное открытие сохраняет `.picked`, `Escape` закрывает окно,
   кнопка очистки снимает подсветку и скрывается.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Язык в выдаче | Ищем по языку открытой страницы, у каждого попадания видна пометка языка; переход в другой язык - осознанный, а не случайное попадание в `de/07.html`. |
| Формат индекса | Файл `.js`, присваивающий глобальную переменную: `fetch` к `.json` по `file://` браузер запрещает, а сайт обязан работать из файловой системы. |
| Куда вставлять | Кнопку и панель собирает `swa.js`; индекс подгружается лениво. Страницы не трогаются, работа переводчика не задевается. |
| Морфология | Не нужна: подстрока по нормализованному тексту (нижний регистр, `ё` → `е`) ловит русские приставки и корни. |
| Подсветка в тексте | Динамическая через `swa.js` в рантайме: разметка страниц на диске остаётся чистой; свёрнутые шаги с совпадением раскрываются автоматически. |
| Очистка подсветки | Динамическая кнопка в шапке левее поиска (`.clear-mark-btn`), видна только при активной подсветке, оформлена в едином стиле с кнопкой сброса в строке поиска (`.search-clear`). |
| Заголовок окна поиска | Не делать: строка ввода с лупой, подсказкой и бейджем языка самодостаточна и сохраняет полезную высоту экрана. |

## Границы: что в задание 14 не входит

1. **Поиск сразу по всем языкам.** Не сейчас: языки в разной степени готовности, и выдача
   смешивала бы переведённое с непереведённым.
2. **Перенос в детский сайт.** После приёмки, вместе с остальным движком.
