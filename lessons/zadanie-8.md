## Задание 8

**Хочу:** перевести сайт с плоского корня на раскладку референс-проекта - страницы по папкам
языков (`ru/`, `en/`, `uk/`, `de/`), оснастка в `assets/`, проверки и генераторы в `tools/`,
файлы занятий в `lessons/` - и заменить эмодзи-значки навигации на встроенный SVG, не изменив
ни одной фразы содержания.

**Предикаты:**

1. **Раскладка на месте, корень чист, история файлов не потеряна.** В корне остались только
   `index.html`, `check.sh`, `README.md`, `AGENTS.md`, `CLAUDE.md`, `LICENSE`, `package.json`,
   `.gitignore` (и служебные `.agents/`, `.claude/`, `.git/`). В каждой из папок `ru/`, `en/`,
   `uk/`, `de/` - по 17 страниц с одинаковыми именами: `index.html`, `01.html` … `15.html`,
   `glossary.html`. В `assets/` - `style.css`, `swa.js`, `cp.js`, `terms.js`; в `assets/img/` -
   `ai-badge.png` и `ai-badge-invert.png`. В `tools/` - `check-page.sh`, `check-claims.sh`,
   `check-links.py`, `build-nav.py`, `glaza.mjs`. В `lessons/` - `zadanie-N.md`, `zapis-N.md`,
   `potom.md`, `review-gemini-1.md`; имена этих файлов не менялись. Корневой `index.html` -
   страница выбора языка: четыре видимые ссылки и переход на `ru/`, работающий без JavaScript.
   Страницы переехали через `git mv`, и `git log --follow ru/01.html` показывает коммиты,
   сделанные до переезда. Документы упряжи (`AGENTS.md`, `README.md`, `check.sh`) называют
   новые пути: ни одной команды со старым путём в них не осталось.
   **Чем проверяется:** машиной - список файлов корня и каждой папки, `git log --follow`,
   поиск старых путей в документах.

2. **Ни одна ссылка не потерялась, и линейка лежит в репозитории.** `tools/check-links.py`
   проверяет все внутренние `href` и `src` и все якоря `#id` на 68 страницах и печатает два
   числа: сколько ссылок и сколько битых. Битых - 0, а число ссылок не меньше замера, снятого
   **до** переезда (замер записывается в `zapis-8.md`). Нигде в репозитории не осталось упоминаний
   `-en.html`, `-uk.html`, `-de.html` и пути `imgs/`. Корневой `./check.sh` - тонкое запускало:
   вызывает всё из `tools/` и печатает одно ЗЕЛЁНОЕ или КРАСНОЕ, включая проверку страницы,
   `check-claims` (20 из 20), `check-links` (0 битых) и `glaza.mjs` **одной командой по всем
   68 страницам**, а не по одной.
   **Чем проверяется:** машиной целиком - `./check.sh`.

3. **Квадратиков вместо значков на сайте нет, и оснастка работает как до переезда.** Эмодзи
   `📖` и `🎯` заменены встроенным SVG в навигации и в словаре на всех 68 страницах; в HTML
   репозитория не осталось ни одного символа из блоков эмодзи. На странице каждого из четырёх
   языков глазами проверено: тема день/ночь переключается и запоминается, три размера шрифта
   работают, переключатель языков ведёт на существующую страницу во все четыре стороны, кнопка
   копирования копирует и подтверждает, карточка термина открывается, боковой навигатор
   подсвечивает раздел при прокрутке, ссылка в словарь открывает нужный термин. На `telefon.png`
   слова не наезжают друг на друга. **И отдельной проверяемой строкой: на дне страницы панель
   навигации показывает свой первый пункт.** Сейчас липкая панель упирается в границу сетки и
   уезжает вверх на 118px - первые два пункта недостижимы ни прокруткой панели, ни прокруткой
   страницы; измерено в браузере на четырёх страницах и трёх высотах окна.
   **Чем проверяется:** поиск эмодзи - машиной; липкая панель - машиной (проба мерит, на сколько
   пикселей панель спрятана над окном, когда страница на дне: должно быть 0 на всех 68 страницах);
   поведение оснастки - глазами Приёмщика.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Язык | Папка, а не суффикс: `01-en.html` → `en/01.html`. Суффикс не масштабируется и даёт 68 имён вместо 17; переключатель языков становится механическим. |
| Корневой `index.html` | Страница выбора языка с переходом на `ru/` и четырьмя видимыми ссылками - работает без JavaScript и для поисковиков. Публичный адрес сайта не меняется. |
| `check.sh` | Остаётся в корне тонким запускалом с одним ЗЕЛЁНЫМ или КРАСНЫМ: одна зелёная проверка - часть словаря метода. Реализации уезжают в `tools/`. |
| `zadanie-N.md` / `zapis-N.md` | Не переименовываем, только переносим в `lessons/`: это словарь метода, на него ссылаются скил, дизайн-книга и детский курс. Папки - по-английски, по правилу 8. |
| Порядок внутри занятия | Сначала линейка, потом переезд: `tools/check-links.py` и базовый замер **до** `git mv`. Иначе переезд нечем принимать. |
| Порядок занятий | Структура → SVG-значки → поиск по сайту → переводы. Каждое следующее трогает те же пути, поэтому структура первая. |
| Переводы | Отдаются Жемини после заморозки русского, по одному языку за задание, в порядке `EN` → `UK` → `DE`; пробный кусок - `en/glossary.html` на 22 термина. |
| Коммиты | ИИ готовит изменения и даёт готовые команды `git commit` на английском; коммитит и пушит Архитектор. Строку `Co-Authored-By:` не добавляем (корневой `AGENTS.md`, пункты 5 и 10). |

## Границы: что в задание 8 не входит

1. **Перевод страниц на `EN`, `UK`, `DE`.** Занятие 9, исполнитель - Жемини. Не сейчас:
   переводить до переезда значит переводить дважды.
2. **`tools/check-struct.py`** - сверка переведённой страницы с русским оригиналом. Не сейчас:
   линейка пишется в начале занятия 9, вместе с заданием на перевод, по тому же правилу
   «сначала линейка».
3. **Поиск по сайту.** Занятие 10. Не сейчас: инструмент добавляется в панель через `swa.js`,
   поэтому страниц он не трогает и может идти параллельно с переводом.
4. **Любая правка содержания страниц.** Ни одной фразы, ни одного примера, ни одного вопроса.
   Не сейчас: переезд должен быть доказуемо механическим - содержательная правка в том же
   проходе лишает приёмку этого доказательства.
5. **Исполнение примеров со страниц `10`-`12` проверкой.** Отдельное занятие. Не сейчас:
   нужны заглушки для сети и облака, это работа объёмом с занятие.
6. **Обновление дизайн-книги** разделом о раскладке референс-проекта. Не сейчас: записываем
   по факту, когда раскладка отработает в деле хотя бы одно занятие.
7. **Вынос оснастки в общий источник и перенос движка в детский сайт.** Не сейчас: сначала
   раскладка должна устояться здесь.
