## Задание 3

**Хочу:** кнопку копирования в каждом блоке кода. Блоков кода на сайте будет только больше, и чем позже это делать, тем больше страниц придётся трогать.

**Предикаты:**

1. **Кнопка есть, работает и доступна.** В каждом блоке кода на содержательных страницах (RU и EN) в правом верхнем углу стоит кнопка копирования. Нажатие кладёт в буфер обмена **точный текст блока** - без номеров строк и без добавленных пробелов. После нажатия на полторы секунды появляется подтверждение «Скопировано» / «Copied». Кнопка **видна всегда, а не по наведению** - на телефоне наведения не существует; доступна с клавиатуры (`Tab`, затем `Enter`); имеет `aria-label`, а значок скрыт от синтезатора речи.

2. **Работает и у автора, и у читателя.** Страница, открытая по `file://`, копирует так же, как опубликованная по `https`: если `navigator.clipboard` недоступен, срабатывает запасной путь. Ни в одном из двух случаев в консоли браузера нет необработанной ошибки. В режиме печати кнопки нет - в PDF-брошюре она бессмысленна.

3. **Машина подтверждает.** `node glaza.mjs` на всех двенадцати страницах печатает «за край ничего не вылезло» и возвращает 0 - кнопка никуда не уехала и первая строка кода не ушла под неё. `./check.sh` печатает ЗЕЛЁНОЕ.

## Решения Архитектора

| Вопрос | Решение |
| :-- | :-- |
| Где живёт код | Отдельный файл **`cp.js`**, не в `swa.js`. `swa.js` - движок страницы, одинаковый для всей серии и для всех страниц; копирование нужно только там, где есть код. Имя `cp` на сайте про Bash объясняет себя само. |
| Куда подключается | Только на содержательные страницы (`index`, `01`, `glossary` в RU и EN). На заглушках UK и DE блоков кода нет - там файл не грузится. |
| Видимость кнопки | Всегда, приглушённо. Так же, как уже сделаны якоря `#`, и по той же причине. |

## Границы: что в задание 3 не входит

1. Подсветка синтаксиса в блоках кода - это внешняя библиотека, а их на сайте нет.
2. Нумерация строк.
3. Кнопка «скопировать всю страницу» или «скопировать раздел».
